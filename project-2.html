Course Planner

A course planning platform that helps teachers organize lessons, schedules, and important academic dates throughout the semester.

Project Overview

Course Planner is designed to assist teachers in managing classroom activities and preparing lesson schedules. The platform provides a structured view of courses and helps educators keep track of important events, deadlines, and teaching plans.

Key Features

  • Course Organization
  • Lesson Scheduling
  • Academic Calendar Tracking
  • Responsive and User-Friendly Interface

Technologies Used

HTML, CSS

What I Learned

Developed a responsive website using HTML and CSS while practicing semantic page structure, layout design, navigation, and content organization. Improved my understanding of creating user-friendly interfaces for specific target audiences.
