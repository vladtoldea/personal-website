Budget Tracker

A personal finance application that helps users track income, expenses, and monthly spending habits.

Project Overview

Budget Tracker allows users to record their income and expenses in order to better understand their financial situation. The application categorizes transactions and provides a simple overview of spending, helping users make more informed budgeting decisions.

Key Features

  • Income and Expense Tracking
  • Transaction Categorization
  • Monthly Budget Monitoring
  • Financial Summary Reports

Technologies Used

Java, HTML, CSS, IntelliJ IDEA

What I Learned

Developed a Java application that stores financial data and performs basic calculations on user-entered transactions. Improved my understanding of ArrayLists, data organization, user input handling, and designing practical software solutions for everyday problems.
